# 🚀 Upendra Murmu — Portfolio

A modern, animated personal portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

### 🔗 **[View Live →](https://upendra-portfolio.vercel.app)**

---

## ✨ Features

- **Smooth Animations** — Page sections animate into view with Framer Motion
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile
- **Dark Theme** — Sleek, modern dark UI throughout
- **Sections** — Hero, About, Skills, Experience, Projects, Creative, and Contact
- **Fast & Lightweight** — Built on Next.js App Router for optimal performance

## 🛠️ Tech Stack

| Category     | Technologies                                  |
| ------------ | --------------------------------------------- |
| **Framework**| Next.js 14 (App Router)                       |
| **Language** | TypeScript                                    |
| **Styling**  | Tailwind CSS                                  |
| **Animation**| Framer Motion                                 |
| **Deployment** | Vercel                                      |

## 📂 Project Structure

```
├── app/
│   ├── layout.tsx        # Root layout with fonts & metadata
│   ├── page.tsx          # Main page composing all sections
│   └── globals.css       # Global styles & Tailwind directives
├── components/
│   ├── Hero.tsx           # Landing hero section
│   ├── About.tsx          # About me
│   ├── Skills.tsx         # Technical skills
│   ├── Experience.tsx     # Work & internship experience
│   ├── Projects.tsx       # Featured projects
│   ├── Creative.tsx       # DSA & creative pursuits
│   ├── Contact.tsx        # Contact form / info
│   ├── Navbar.tsx         # Navigation bar
│   └── Footer.tsx         # Footer
├── lib/
│   └── data.ts            # All portfolio content & data
└── package.json
```

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Monsoon-19/portfolio-1.git
cd portfolio-1

# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.
